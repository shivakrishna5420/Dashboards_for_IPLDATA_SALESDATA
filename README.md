Store Sales Dashboard – Power BI Project
Overview

This project is a Power BI Store Sales Dashboard designed to analyze and visualize store performance data using interactive reports and dashboards. The report provides insights into sales trends, product performance, customer behavior, and regional analysis.

The dashboard was created using Microsoft Power BI to transform raw business data into meaningful visual insights that support decision-making.

Features
Interactive sales analysis dashboard
Product and category performance tracking
Revenue and profit visualization
Regional and location-based insights
KPI cards for quick business overview
Charts, maps, slicers, and tables for better analysis
User-friendly and dynamic report navigation
